# Triage Labels

The `triage` skill uses the following label vocabulary to manage the issue lifecycle.

## Label Mapping

| Role | Label Name |
| :--- | :--- |
| Needs evaluation | `needs-triage` |
| Waiting on reporter | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Will not be actioned | `wontfix` |

## Lifecycle

The `triage` skill moves issues through these states using these labels.
